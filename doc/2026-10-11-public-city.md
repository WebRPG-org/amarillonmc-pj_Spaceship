# 公共城市扩张

## 设计约束

新建 Map040–048，作为局外共享场景；不加入副本地图集合，不新增战斗、奖励或收费。标准 48px、六平面 RPG Maker 地图，由本项目独立浏览器 Renderer 与 World 运行。原 Map031–039 副本保留。出生点改为城市街区，远征与外观服务从旧出生图迁出，旧调试事件留原地。

远征和外观服务使用地图中的 `engine_service: instance` / `engine_service: appearance` 事件，服务端只绑定原事件，不另生成重复角色。位置以编辑器事件为准，服务 runtime ID 保持稳定。合成工匠由 Map003 event8 搬至 Map042 event8，原选择分支与 `Composition 1` 命令保留；旧位置置空，没有挪动其它旧事件。

新引擎新角色按 System.json 出生；原 Map001 的局外存档首次登录迁至新街区并记录 `publicCityVersion`，库存、外观和事件状态保留。其他地图存档不强制搬家，玩家以后主动回 Map001 也不会再次迁移。副本退出仍恢复入局前保存的位置，通常为广场 NPC 旁。旧 MV/RethinkDB 登录保存逻辑未迁移，实际内测入口使用 8098 新引擎。

政务窗口、住户和向导只提供说明；商品陈列未新增购买机制，也未增加奖励或任务。旧测试房的送物资、清空背包与中毒等事件没有搬到公共城市。

## 验证与修正记录

全图采用统一 24px/格，整批对照统一 12px/格并保留真实宽高比；26 个关键玩家视口为816×624、48px/格，带实际 Actor 和 World.snapshot 初始事件状态。产物在 `engine/.artifacts/public-city/`，`render-report.json` 记录地图哈希、视口、资源错误和事件数。截图是实际 Renderer 证据；移动、传送、对话另由真实 World 与网络集成测试执行。

| 问题 | 修改与复核 |
| --- | --- |
| Map040 (39,15) 回程落点撞路灯 | 路灯移至 (38,13)，所有回程保持精确落点，通行复验通过 |
| 出生在机动车道，入口观感弱 | (20,23) 改为黄砖迎宾步行区，附近设置城市向导与成组花坛 |
| 美容工作室浮空电视／桌面 | 改为完整收银台、衣柜、镜台和茶几；重新查看全图与服务视口 |
| 电脑桌缺前沿柜体 | 门厅、住宅、政务厅全部补126/127底座，重新检查角色站位 |
| 大厅误用水槽作茶几 | 两处换完整茶几；与座椅组成等候区 |
| 大厅进门视口看不到接待功能 | 完整接待台与接待员移至入口左前方 (9,17)/(10,20)，避开座椅 |

| 商店中央空走及冷柜裁切 | 增加完整第二排陈列通道，冷柜宽度改为3格，移除误当续块的海报 |
| 公园秋千/船误接续块 | 秋千改2×1，船保留2格完整船身，池北增加完整散步台与长椅 |

自动检查包括每个实际入图落点到所有出口与NPC交互邻格、逐格触碰传送及返回、出生/回城/服务绑定、旧存档迁移、地图非副本属性及无敌人/箱子。真正 MySQL、HTTP、WebSocket 集成另行执行。新增地图内容报告无不支持命令；全工程只读清点仍报告旧地图既有 `4scientist` / `DF_Actor` 缺图，本次新图不引用它们。

最终 `npm --prefix engine test`：137 项，133 通过、4 个数据库测试默认跳过、0 失败；`npm --prefix engine run test:integration`：23 通过、0 跳过、0 失败。新公共地图专用测试23项，包含搬迁后合成工匠真实交互、选择分支、9项原配方及不额外发放物资的检查。8098服务载入48图，45图可传送，3张旧空图继续明确拒绝。

本轮没有进行多人长时间游玩或完整旧 MV 插件实机验收。标准 MV JSON 可编辑不意味着旧 MMO 插件已实现新引擎的副本及外观功能。
