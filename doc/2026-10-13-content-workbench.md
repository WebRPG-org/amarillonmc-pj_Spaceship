# 内容工作台与本机运行管理

入口为 `http://127.0.0.1:8098/editor`。在 `engine/.env` 设置 `DEV_TOOLS=1`，服务绑定 `127.0.0.1` 后重启。玩家客户端开发区也提供入口。工作台直接读取工程文件，无须登录游戏；运行管理需要服务连接数据库并已有玩家或副本。

## 首版可以实际编辑的内容

| 页面 | 保存目标和运行用途 |
| --- | --- |
| 副本规则 | `engine/content/gameplay.json` 的副本名、说明、地图集、室外地图、时限、人数、出生点、初始等级／职业／背包／装备／金钱／技能、允许头衔、磁盘目标、目标提示、永久头衔／金钱／物品奖励、箱子模板物品、陨石间隔／预警／伤害、飞火流星引导与 MP 倍率 |
| 地图与实体 | 真实图块预览，点选已有事件或创建事件，编辑名称、坐标、首事件页图像、NPC／结构／磁盘／出口／商店标签；保存至原 `data/MapNNN.json` |
| 经济与奖励 | 主世界或 DTS 商店、商品和价格、卖出比例、只买开关；独立实时 NPC 属性、掉落数量和概率、金币和经验；永久头衔和赠予武器；可破坏结构耐久 |
| 实时武器与工具 | `Weapons.json` 的文字、价格和四种 `serverWeapon` 模式，保留其他 note；现有 Tool Map 注释通过表单生成范围、形状、时长、技能、物品、弹药和穿透参数 |
| 动画资源 | 同时列出 MV 帧动画和 MZ Effekseer，复用独立客户端的实际渲染器预览；编辑名称、图集或效果资源，MZ 缩放、速度、旋转、偏移、显示位置和底部对齐 |
| 运行管理 | 查看在线／离线留场角色及其背包、装备、状态和资料；查看运行副本和诊断；断开玩家连接、结束故障副本并退回主世界、发送管理员公告 |

局内外的背包与金钱使用各自的运行存储。商店配置中的 `scope` 和所在世界不一致时不能使用。标题奖励和支持该标题的副本都需明确配置；编辑一个头衔并不会自动允许全部副本使用。

地图实体表单使用运行时已有的 `engine_npc`、`engine_structure`、`engine_service`、`engine_shop` 和 `engine_container` 标签。NPC／商店／结构／箱子物资定义只有 sidecar 一份；地图标签只是引用。箱子模板可在副本页面添加并逐项编辑物品；每个地图事件每局领取一次。工具的运行导入器仍以 Tool Map 为来源，表单生成原生 108／408 注释指令，不产生另一份未消费的工具配置。

## 保存与 RM 共存

每次打开文档取得 SHA-256 内容版本。保存传递版本与允许字段的修改；若 RM、另一窗口或开发者已经改过文件，返回 409，要求重新读取，不覆盖对方内容。同一服务中的竞争保存按文件串行化，写入临时文件后替换原文件。

保存前把旧内容备份到 `engine/.artifacts/editor-backups/`，界面显示具体备份路径。地图只合并选中事件的允许字段，原地图图块、其他事件、页面条件、路线、任意已有指令及未知扩展字段均保留；新事件使用合法 RM 条件、图像、路线和结束指令模板。动画只改选定动画的允许字段，原帧、时序和其他格式数据不删除。配置对象的未修改和未知字段保留。

保存后需重启服务，再刷新客户端；正在运行的副本不热更新。恢复备份时先停止服务，检查备份对应文档，再把该备份复制回明确的原路径；没有自动批量恢复或清空工程操作。

这不等于已验证“同一混合动画数据库可在 MV、MZ 本体中任意往返保存”。原生编辑器仍有版本和动画格式差异；特别是旧兼容占位字段不能当作安全转换证明。工作台保留双方字段，不冒充原生编辑器转换器。

## 访问边界

- 编辑和管理 API 只接受 `DEV_TOOLS=1` 且真实 socket 来源为 loopback 的请求。
- Host 也必须是 localhost／loopback；有 Origin 时必须与 Host 相同。带常见代理转发头的请求被拒绝，不能把 `HOST=localhost` 当成远程代理访问授权。
- 修改要求专用请求头，浏览器跨站表单不能直接提交。没有远程密码入口，也不提供对外部署模式。
- 文档种类、地图数字 ID、修改字段均采用白名单；检查真实文件路径和父目录的解析结果，阻止路径穿越和工程外符号链接／目录联接。
- 写入体最大 1 MB；校验地图、物品、职业、技能、头衔引用及数值范围；不执行脚本或接收任意文件路径。

## 明确边界

首版是内容制作工作台，不是完整 RM 编辑器复刻。没有瓦片画笔、自动图块绘制、填充、撤销历史、完整数据库编辑或任意事件指令编辑；继续使用 RM 绘制地图和编写原生剧情事件。

当前 Local 新建配置以“回收目标物品、从入口撤离”作为可用冒险模板。DTS 仍沿用现有封锁乡野路线，校验要求保留地图 11、12、13、20、21、22，可加入扩展地图。修改地图集仍需要保留目标事件，不表示已获得通用任务图或任意规则编辑器。

MV 帧时间轴和 Effekseer 粒子内部制作仍由对应工具完成。MV 原色相／位置字段保存时保留，但独立预览渲染器尚未完整适配其语义，所以不提供误导性的编辑控件；预览以落点为中心。Tool Map 的旧 `tool position` 也只保留，当前实时攻击从施放者位置开始。

管理页当前以运行内存里的角色为范围，没有离线全账号检索、任意改物品、封禁系统、审计报表或持久化公告。断开连接遵循原有离线留场规则，不能把它误认为删除角色或封号。
