# 离线行动、鼠标操作与武器扩展

日期：2026 年 10 月 11 日，UTC。承接[可游玩副本与永久外观](2026-10-11-playable-instances.md)之后的实施记录。前一记录中“仅停留”“尚不支持 Effekseer”等描述保留为当时状态，当前功能以本文及[引擎说明](../engine/README.md)为准。

## 本次范围

本轮补齐断线后的自动行动、地图鼠标／触屏控制、真实 MZ Effekseer 效果，以及有不同攻击方式和资源消耗的武器。继续使用 RPG Maker 编辑地图、数据库与 Toolmap；线上移动、攻击、伤害、物品变化和副本规则由新服务端执行。地图画面打开菜单时仍持续接收快照，客户端不会成为战斗判定者。

## 四种离线策略

在侧栏「离线行动」选择策略。设置存入 MySQL 的永久 profile，与自定义外观一起独立于局内背包；普通世界和副本都保留断线角色。再次连接时停止自动行动，将当前角色状态交回玩家。

| 策略 | 实际行为 |
| --- | --- |
| 停留 `stay` | 原地等待，继续受到敌人和禁区伤害，不自动移动或攻击。 |
| 躲避 `evade` | 发现附近敌对目标时寻找更安全的可达位置；无威胁时待机。 |
| 探物 `search` | 搜刮可达地面掉落与副本共享补给箱；没有目标时尝试经安全静态入口探索其他区域，遇敌先躲避。 |
| 追杀 `hunt` | 追击有视线的敌对目标，使用当前武器正常攻击；生命不高于 30% 时转为躲避。没有可见目标时警戒。 |

除停留外，策略都会优先尝试离开已生效或即将生效的禁区。目标判断使用当前地图的敌对关系，PvE 不会把友方玩家当作可攻击目标；追击视野有距离和墙体限制。AI 走真实通路与入口，不直接修改地图坐标或瞬移。条件复杂、脚本控制或变量决定的传送不作为可推断的跨图路线。

自动拾取、箱子领取和攻击仍走原本的服务端距离检查、库存事务、冷却与资源消耗。缺弹药、缺 MP、耐久不足或路径被堵时不会凭空补充资源；重新规划或等待。探物不会自动装备捡到的武器，离线前应安排装备。这是有限规则的行为控制器，不保证角色存活、自动解谜或完整通关。

断线与进程停止不同：服务运行时继续模拟离线角色；服务重启仍按既有规则中止未完成副本，不能在进程未运行时继续世界模拟。

## 鼠标和触屏

| 输入 | 行为 |
| --- | --- |
| 单击／轻触地面 | 显示目的地，按服务端通行和实体碰撞寻路。 |
| 按住并移动指针 | 指向新格子时更新目的地。 |
| 单击可见 NPC 或机关 | 靠近至交互距离并操作。 |
| 单击掉落物或背包 | 靠近后拾取；死亡背包仍一次领取全部内容。 |
| 单击敌人 | 使用当前选定技能；靠近或进入可攻击位置后发起攻击。PvP 地图也可点击其他玩家。 |
| 单击传送入口 | 实际走到触碰位置再换图，不绕过入口进行远程传送。 |
| 右键 / Escape | 取消路径并打开或关闭背包；对话选择的取消由原事件允许的分支决定。 |
| 触屏双指 | 取消／菜单操作；两根手指抬起不产生遗留的移动点击。 |
| WASD / 方向键 | 接管移动，取消此前鼠标路径。 |

键盘攻击、交互、背包按钮保留。打开面板、失去焦点、断线或切换地图会取消旧导航。内容预览中点击只改变观察中心，不产生账号移动或联网交互。导航请求携带副本上下文，服务端拒绝来自旧世界的操作。

寻路为有界四方向搜索，避开非目标传送口；明确点选的阻挡式触碰入口允许尝试最后一步，由既有事件触碰规则执行传送。当前控制方式保留 MV/MZ 的地图点选习惯，同时增加 ARPG 敌人目标点击；不加载原引擎的输入或寻路代码。

## 新武器、技能和 Toolmap

定义写入标准 RPG Maker 数据文件：`Weapons.json` 的 61–64、`Skills.json` 的 301–304、`Items.json` 的 101，以及 `Map025.json`（Toolmap）的事件 100–103。原有条目保留。装备后选择「普通攻击」即可按当前武器切换攻击定义，不需要先学会其专用技能；直接调用其他武器的技能不能绕过装备要求。

| 武器 ID／名称 | 技能／Toolmap 事件 | 范围与方式 | 每次攻击消耗 | 初始耐久／冷却 |
| --- | --- | --- | --- | --- |
| 61 回旋投刃 | 301／100 | 6 格远程弹道，首次命中结束 | 1 耐久 | 24／0.5 秒 |
| 62 短管火枪 | 302／101 | 8 格远程弹道，首次命中结束 | 1 发制式弹药（Item 101） | 不设耐久／0.7 秒 |
| 63 余烬法杖 | 303／102 | 7 格火焰弹道，首次命中结束 | 1 耐久与 4 MP | 30／0.6 秒 |
| 64 重型棒槌 | 304／103 | 周围曼哈顿距离 2 格的菱形近战范围 | 无弹药、MP 或耐久成本 | 不设耐久／1 秒 |

远程弹道受墙体与最大射程约束；粒子只是表现，不决定命中。投刃目前作为可反复使用且磨损的投掷武器，没有返航拾回的物理过程。火枪直接扣除库存弹药，尚无独立弹匣或装填动作。耐久归零后不能继续使用需要耐久的攻击，应换一件武器；本轮没有新增完整修理经济。

武器物品按单件生成 `instanceId`。同种武器不合并耐久，装备状态保存具体个体；整理、丢弃、死亡整包掉落、整包领取与重登录保留各件的磨损。攻击在数据库提交成本后才产生服务端攻击实体，请求编号用于避免重复扣费和重复出手。

攻击规则来自武器备注里的数据标记，例如：

```text
Tool Id : 102
<serverWeapon>{"mode":"staff","range":7,"maxDurability":30,"durabilityCost":1,"ammoItemId":0,"ammoCost":0,"mpCost":4,"skillId":303,"toolId":102}</serverWeapon>
```

`serverWeapon` 是新引擎验证过的数据格式，不是 JavaScript。Toolmap 保留 `tool_skill_id`、`tool_range`、`tool_max_distance`、`tool_projectile`、`tool_speed`、`tool_pose_duration` 等注释，仍可在 RPG Maker 中维护。实际支持范围以导入器和战斗实现为准；添加一个任意旧插件标签不会自动产生新行为。

## MZ Effekseer 接入与来源

本轮使用真实 **Effekseer for WebGL v1.52n** 的 JavaScript／WASM 运行库，在独立透明 WebGL 画布绘制 `.efkefc`，再合入原 Canvas 地图。旧 MV 图像帧动画继续可用。客户端按 MZ 动画定义读取效果名、缩放、速度、旋转、偏移、显示位置、音效时序和闪光时序，并按效果原始格式加载粒子内容。

运行库和所选效果从用户已授权使用的本地资源库取得，来源目录为：

```text
D:/Resources/MVDLC/City Exterior Tileset/sample MZ/sample project_jp
```

仅复制本轮所需文件。运行库位于 `engine/client/vendor/effekseer/`，效果位于根目录 `effects/`，纹理位于 `effects/Texture/`。四个 MZ 动画定义追加至 `data/Animations.json`：

| 动画 ID／名称 | 效果文件 | 用途 |
| --- | --- | --- |
| 121 MZ · 投掷穿刺 | `effects/ArrowSpecial.efkefc` | 投刃命中表现。 |
| 122 MZ · 火器射击 | `effects/ShootNormal.efkefc` | 火枪命中表现。 |
| 123 MZ · 火焰法杖 | `effects/FireOne1.efkefc` | 法杖命中表现。 |
| 124 MZ · 重棒冲击 | `effects/HitPhysical.efkefc` | 棒槌攻击表现。 |

依赖纹理为 `Arrow.png`、`Fog.png`、`LightRing.png`、`Particle100.png`、`ParticleAlpha.png`、`Rock.png`、`ThunderC.png`。逐效果依赖清单和来源记录见 [SOURCE.json](../engine/client/vendor/effekseer/SOURCE.json)。浏览器需要 WebGL 和 WASM；加载失败会记录诊断，服务端伤害与消耗不会因表现失败而停摆。

当前仓库是 **MV 编辑器工程**。新增动画 121–124 保留完整 MZ 效果字段，同时附带空的 MV 占位字段 `frames`、`timings`、`animation1Name`、`animation1Hue`、`animation2Name`、`animation2Hue`、`position`，用于让旧 MV 运行时安全结束动画，避免读取 `frames.length` 时崩溃；这不表示旧 MV 能播放或编辑 Effekseer。新引擎优先识别 `effectName`，实际仍播放 MZ 粒子效果，且也接受没有占位字段的纯 MZ 记录。

若将这四条混合记录复制到**原生 MZ 工程**，须先删除上述 MV 占位字段，尤其是 `frames`：原生 MZ 的 `Spriteset_Base.isMVAnimation` 使用 `!!animation.frames` 判断格式，即使空数组也会被当作 MV 动画。复制后应由 MZ 编辑器维护 `effectName` 及相关粒子参数；在 MV 编辑器中重新保存动画数据库可能丢弃额外 MZ 字段，应保留这四条记录的备份并在保存后检查字段与编号。

运行库代码的 MIT 许可保留在 [LICENSE](../engine/client/vendor/effekseer/LICENSE)。**运行库许可与游戏素材授权分开**：RPG Maker、DLC 样例的效果、纹理、音效和其他素材仍受其原有授权约束，不能把这里的 MIT 文本视为这些素材的新许可。本轮记录的是来源和复用范围，没有重新授权素材。
