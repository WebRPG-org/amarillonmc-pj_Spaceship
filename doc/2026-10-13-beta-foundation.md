# 内测基础与「飞火流星」单人冒险

本轮把永久角色、独立副本、完成奖励和内容制作接成可玩的流程。新内容使用独立实时 NPC 定义，继续读取原生 RM 地图和非战斗事件；没有把 RM 回合制战斗、敌群或战斗场景移进新玩法。

## 如何体验

按 `engine/README.md` 启动项目 MySQL 和引擎，浏览器打开 `http://127.0.0.1:8098`。新账号从中央街区前往榆风广场，与远征接引员交谈，在大厅选择「飞火流星 · 废城回收」，再点「开始副本」。

路线为城郊 52 → 商街 53 → 中心广场 54 → 档案楼 56，取盘后原路返回城郊撤离信标。商街另通向避难所 55。磁盘与撤离点都有明确事件标记；单击目标自动靠近交互，也可面向目标按 E。移动、对话、打开背包和断线均不会暂停时限。

通关后在侧栏「饰品／头衔」装备「飞火流星」。下次进入「封锁乡野」DTS 会在背包获得同名武器；手动装备后用普通攻击发动。当前单人回收冒险不允许这个头衔，避免奖励反过来改变其基础状态挑战。

## 状态、物品和奖励

- 主世界存档继续保存位置、等级、HP／MP、背包、金币、参数和事件状态。永久资料保存外观、离线行为、已获得头衔与当前装备的头衔。
- DTS 每局重置为 LV1、零金币、校服、面包 ×2、矿泉水 ×2、基础技能和配方书。废城冒险使用同样的基本状态，但没有配方书。
- 头衔入场效果同时要求“已获得”“已装备”“副本允许”。只携带对应武器，不自动替换玩家选择的装备。局内无法更换永久头衔。
- 局内物品、金币、经验、伤势和状态不带出。退出时恢复主世界存档，服务端配置的完成奖励另行结算；这不会把整个局内背包合并回主世界。
- 废城成功仅解锁「飞火流星」，不额外奖励金币。重复完成不会重复收藏头衔。死亡、超时、主动退出和管理员中止均没有完成奖励。
- 通用冒险奖励可配置永久头衔、金币和指定物品，供后续 Local PvE／剧情内容复用。
- 行动档案显示本人最近 30 次记录，包括个人提前离开以及整局最终结算。账号之间不能互相读取档案。

## 商店、NPC 与制作数据

主城 Map042 店员使用主世界钱包；DTS Map011 补给商人使用局内钱包。商品、价格、买卖权限和回收比例来自内容配置。每次交易都检查实际店员、当前地图、角色距离、金币和库存；玩家客户端不能自定价格或跨世界交易。武器逐件出售，装备在售出后正确解除。

实时 NPC 模板有自己的 HP／MP、攻防参数、金币、经验与掉落表。现代区既有巡逻 NPC 已迁到这些模板。玩家击杀时金币和经验给击杀者，物品留地；环境击杀时物品和金币均落地，不凭空指定受益玩家。路障使用独立结构模板，没有 RM 敌群依赖。

新增 RM 数据为 Items 102–104、Weapon 65、Armor 121、Skill 305。数据库仍采用原生数组、原生字段和每条记录一行的格式，旧 ID 保留。`build-beta-data.mjs` 可以重建这批初始定义；它会拒绝覆盖同 ID 的其他已命名内容，因此后续作者改名时不要直接重跑生成器。

同步澄清了配方书和几种既有恢复物的说明，删除一条重复 HP 恢复效果；合成面板显示已持有／所需材料、缺料和产物说明。

## 保存与异常恢复

- 每局使用独立 `RoundStore`，主世界物品和实例物品的 SQL 表、请求记录分别隔离。
- `finishRound` 在同一事务内锁定本局结果、有效参与者、主世界角色和永久资料，写入结果与奖励。重放、并发结算及响应丢失后的重试返回同一结果。
- 修改外观、离线策略或装备头衔时只合并相应资料字段，避免覆盖同时发放的永久收藏。
- 无主环境掉落使用 `world_drop_requests` 按世界作用域和请求 ID 去重；重试只返回仍然存在的掉落，不把已拾取物品重新放回画面。
- 交易与武器扣 MP 保留已有事务不确定状态恢复。进入室内、死亡或离开期间尚未完成的施法，也不能在提交回调返回后重新启动。
- 无效副本定义在写数据库前拒绝；构造失败会关闭新建房间；创建容量在异步写库前预占，防并发突破上限。32 局是保护上限，未作为容量压测结论。
- 服务器重启仍中止未完成副本，保留主世界角色、永久奖励与记录；不会从崩溃点逐帧恢复整局。

## 内容工作台与本机管理

启用 `DEV_TOOLS=1`、绑定回环地址后访问 `/editor`，也可用玩家开发区的链接。可编辑副本、出生状态、室外地图、陨石、箱子、奖励、NPC、商店、头衔、结构、实时武器、Tool Map，以及在真实地图上摆放和修改实体。MV 帧动画与 MZ Effekseer 在同一个预览器中播放。

保存检查文件版本冲突，备份原始字节，保留未修改的 RM 字段。启动和内容检查会校验规则与引用。后台提供当前角色查询、断开连接、查看／终止副本、公告和运行诊断。

当前是内容工作台首版。瓦片画笔、完整事件指令树、MV 帧动画制作时间轴、Effekseer 节点编辑、远程团队角色权限以及旧后台所有功能的迁移仍未完成。DTS 编辑基于乡野六张核心地图模板，可增加扩展图；其他全新 DTS 规则需要继续扩展场景实现。工作台能保留混合动画字段，但本轮没有操作 MV／MZ 本体验证互相打开后再保存的完整往返行为。详见 [工作台使用与边界](2026-10-13-content-workbench.md)。

## 验证

运行 `cd engine; npm test`、`npm run test:integration` 和 `npm run content:check`。数据库测试只操作独立 3317 实例中带随机后缀的临时 schema，完成后清理测试 schema，不重置项目账号。

最终结果：单元测试 240 项通过、0 失败；默认跳过的 5 个 MySQL 父组在独立集成测试中执行，共 29 项全部通过、0 跳过。内容检查成功载入 56 张地图。真实玩家 UI 的 7 组检查通过，18 张截图复核，浏览器脚本错误与失败请求均为 0。

- Host 测试以 LV1 正常血量、150 ms 移动节奏，读取实际预警并闪避，完整步行取盘再返回，无开发传送、无限血或清怪。覆盖私人准入、计时、收藏发放、头衔入局、死亡／超时／离开无奖及箱子独立领取。
- MySQL 测试覆盖并发、失败回滚、丢失提交响应、奖励与资料同时修改、环境金币掉落、已拾取掉落重放、档案隔离。
- 地图八项验证覆盖真实碰撞与每条传送往返；实际 Renderer 检查五张全图及十三个玩家视口。另修复 Map040 门牌和 Map044 导览牌既有可达性失败。
- 工作台测试覆盖保存、冲突、备份、路径与目录联接边界、RM 字段保留、模板及引用校验；真实浏览器已播放 MV 和 MZ 两类特效。
- `tools/verify-beta-ui.mjs` 用临时 MySQL、临时端口和关闭开发权限的应用检查玩家 UI；预置的钱和已获得头衔仅用于 UI 夹具，通关资格另由完整路线测试验证。实际点击买卖、装备、入局、发动、取消和档案，同时检查桌面／手机画面、脚本错误及失败请求。截图位于 `engine/.artifacts/beta-ui/`。

这些验证覆盖本轮功能，不代表长时间多人容量、正式公网部署或所有旧插件语义已经验收。
