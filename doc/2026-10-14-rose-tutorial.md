# ROSE 新手单人副本

入口为 Map041「榆风广场」事件 11，坐标 `(25,14)`。与 ROSE 交互后准备并开始「ROSE 的生存课堂」（`rose-orientation`）。副本为单人私人实例，40 分钟；死亡、退出和超时不发奖励，可以免费重试。使用当前实际运行的新引擎，原生 RM 地图、事件、武器、技能及动画仍可编辑。

## 红杀铁剑

首次通关在结算事务内记录永久解锁，并向主世界背包发放 Weapon 66 一把。主世界实际装备这把武器、具有相应解锁记录且 DTS 配置允许时，入场发放独立的局内武器。它不占用飞火流星头衔的装备栏。重复通关、重复结算及失败结算不会重复授予首通武器。课堂借用品属于本局背包。

Weapon 66 → Skill 306 → Map025 Tool 105 → Animation 125。普通攻击对前方紧邻横排三格造成强力物理伤害，四个朝向旋转范围，墙体阻挡，单次挥击对每个目标只结算一次。动画复用项目现有 SlashFire 图像素材制作局部挥斩，并在有效格播放。真正装备时 `movementSpeed = 0.75`，卸下恢复；键盘、自动寻路和离线移动同步应用倍率。

## 验证与复现

- 地图设计、全图、玩家视口和真实碰撞/转场检查见地图记录。
- `npm --prefix engine test` 检查内容、事件、独立实例、武器范围、移动倍率和教程完成/重试。
- 项目 MySQL 启动后，在 engine 下运行 `npm run test:integration` 检查真实事务与结算。
- `node engine/tools/verify-rose-ui.mjs` 在独立临时数据库和随机本机端口运行真实浏览器，通过键盘、背包、攻击、拾取和合成界面完成教程，再检查主世界装备和 DTS 入场。仅初始主城位置为测试配置，不注入进度、伤害或奖励。结果写入 `engine/.artifacts/rose/ui/verification.json`。

本次教程由新引擎承载；标准 RM 文件可编辑不代表旧 MV/MMO 插件具备同样的副本和持久化运行机制。重启新引擎并刷新客户端后载入新增内容。
