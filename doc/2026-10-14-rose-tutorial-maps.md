# ROSE 新手训练营地图

本批新建 Map057–060，并在主世界 Map041 追加独立的 ROSE 教学入口。用户明确要求单人副本、移动和各类武器操作、击败 NPC、搜刮、合成及首通奖励，因此本批教学 NPC、检查点、物资箱、工作台和实战敌人属于已授权机制。进度、Gab 文案、奖励和单人隔离由教程运行时处理。

工程保存标准 RM 六平面地图，运行时是项目自有 `engine/client/renderer.mjs` 和服务端 `World`，不是直接运行旧 MV 插件。沿用 48px 图块；此次视觉验证视口为 816×624。地图继续复用城市 Tileset 39 和现代室内 Tileset 40；没有修改共享图块 PNG 或通行 flags。

## 重建与复核

`node engine/tools/build-tutorial-maps.mjs` 明确重建 Map057–060、其 MapInfos 条目及 Map041 教学入口。只允许空闲 ID 或已带 `engine_adventure: tutorial` 的地图，遇到其他地图会停止。主世界入口按标签原位更新，不重复追加。手工编辑新地图后不要无意重跑生成命令。

```powershell
node engine/tools/build-tutorial-maps.mjs
node --test engine/test/tutorial-maps.test.mjs
node engine/tools/render-public-city.mjs --maps 41,57,58,59,60 --points engine/.artifacts/tutorial-maps/points.json --out engine/.artifacts/tutorial-maps/maps
```

`points.json` 是本地视口配置；缺失时可省略 `--points` 使用渲染工具的默认取景。现有公共城区与旧副本地图不在本批重绘范围。
