# 可完整游玩的副本与永久外观

日期：2026 年 10 月 11 日，UTC。第二阶段实施记录。

## 本次确认的方向

RPG Maker 继续作为地图、数据库与素材编辑器，新引擎负责线上规则。大逃杀是从外部世界向 NPC 搭话进入的副本，不把整个游戏限定为一种模式。保留原工程与旧脚本；本轮不执行任意旧插件 JavaScript。

- 死亡在原地生成一个背包，包含全部随身物品堆叠；拾取一次获得整包。背包支持整理与指定数量丢弃。
- 断线角色原地留场，继续承受战斗与禁区伤害，重连接回当前状态。本轮没有实现自动躲避、探物或追杀 AI。
- 钥匙为不消耗物品，可以丢弃转交；PvE 普通出口解锁后全局共享。
- 第二路线为取得解除组件、解除普通禁区、进入持续禁区挑战 Boss、取得其掉落的终局钥匙、使用终局出口结束本局。
- 自定义外观是永久账号资料，独立于局内背包与成长。恢复原 CharacterCreator 的部件组合与颜色，也允许选用已有 actor 的脸图和行走图。
- 资源库位于 `D:\Resources`，可按需使用；本轮已有素材足够，没有批量复制该资源库。

## 试玩路线

外部出生地图 Map001，出生点附近右侧为「远征接引员」，左侧为「外观调整师」。面向 NPC 按 E。已有账号若停在别处，可用本机开发地图入口返回 Map001，再走到出生点附近。

向接引员搭话后创建 PvE 或 PvPvE 副本。其他账号可在同一 NPC 加入等待中的副本；创建者点击开始。允许一人开局，最多八人，每局二十分钟。副本运行中禁止开发传送、补物资和重生。

测试地图为 Map011 村庄、Map012 旅店、Map013 村屋、Map020 道路、Map021 洞穴、Map022 矿道。保留原地图静态传送关系，新增服务点与共享机关；旧测试奖励与脚本页不进入副本。

普通路线：进入旅店搜刮通行证箱，返回村口，用通行证解锁共享出口，再次交互撤离。解锁不消耗通行证；其他参与者无须持证也可撤离。个人撤离后返回外部世界，其余玩家继续。

Boss 路线：在道路工具箱取得封锁解除组件，到村屋控制台解除普通禁区，再经过洞穴进入矿道。矿道仍持续伤害角色；击败封锁守卫，拾取掉落钥匙，靠近终局出口交互，整局结算并返回外部世界。沿途补给与恢复道具用于战斗和禁区生存。

方向键或 WASD 移动，E 交互，J / 空格攻击，Tab 打开背包。合成与技能选择在右侧。面板打开时服务端世界继续运行。断线与退出账号不会让局内角色消失。

## 数据与兼容边界

`GameHost` 将每个账号路由到一个权威 World；每个副本拥有独立的地图实体、掉落、计时器、机关和参与者状态。同一张源地图可以在多局中复用。客户端命令携带当前副本身份，拒绝上一局的迟到操作。

MySQL 保存外部角色状态、永久 profile、对局与参与者状态、局内掉落及操作去重。角色外观只保存经过校验的 actor ID 或部件和色板选择，不接受任意素材路径。死亡清空背包与生成整包、拾取整包与更新库存均在事务中完成。

外部背包在入局时保留，副本使用独立初始物资；本轮不把局内物资结算成永久经济奖励。正常离场回到外部角色状态。服务重启将未完局明确中止，不宣称能恢复每个弹道、怪物与事件执行位置。

原 CharacterCreator 资源共十八层、十四组选择，包含脸图、四向行走、侧视与倒地素材。恢复的是这些内容的创建、呈现与持久化功能，不是加载旧插件运行时。任意脚本、完整 MZ、所有 ARPG 工具语义、自建远端编辑器、大规模容量和公开运营部署仍属后续工作。

## 验证记录

- `npm test`：58 项通过，3 个数据库测试组按默认配置跳过。包含实际地图通行与原传送口、单人正常攻击击败满血 Boss、钥匙不消耗且可丢弃拾回、全员死亡结算、跨局隔离、离线受伤、结算失败与提交响应丢失后的恢复。
- `npm run test:integration`：21 项通过。覆盖真实 MySQL、HTTP、两个 WebSocket、永久外观、入局与回城、重新连接、迟到的旧局请求、争抢整包、共享容器提交响应丢失后的跨账号重试。
- 独立无头 Edge 浏览器：实际键盘操作打开外观编辑器、换色并保存、向 NPC 搭话创建和开始副本；沿 Map011 → Map012 → Map011 行走，取通行证、解锁共享出口、完成普通撤离并看到回城结算。过程中无页面 JavaScript 异常。
- CharacterCreator 的实际部件路径与原 PIXI 色板矩阵已回归核对；脸图、行走与侧视预览截图已检查。浏览器证明位于 `engine/.artifacts/phase02-appearance.png`、`phase02-round.png`、`phase02-escaped.png`，均为本机生成的忽略文件。

自动测试与浏览器测试都使用实际仓库地图和素材；真实 MySQL 测试限定本项目的 `127.0.0.1:3317`，不操作机器原有的 MySQL57。Boss 路线完成了服务端自动试玩，尚未进行人工手感和平衡测试；八人上限是原型规则，不是容量压测结论。

内置浏览器控制工具因本机沙箱初始化错误未能启动，因此页面核对使用独立无头 Edge；不影响本地游戏服务。测试中未修改原始 `data/`、`img/` 或旧插件文件。
