## 1. 学习素材语法

把相关 Sample 作为一组已经成立的局部组合。结合其地图画面、素材表和工程数据，辨认物件用途及组合条件；仅凭文件名或相邻图块编号不能确认语义。

### 完整物件与组合

- 为床、机台、柜台、泳池、楼梯、座椅排等记录完整边界：主体、底座、顶部、边角、接续段和占用的地面。
- 记录锚点实际代表什么：物件落脚、门前站位、柜台外侧或交互面。不要把素材图左上角自动视为使用位置。
- 区分可重复延长的中段与不可省略的端头；大型对象改变长度时，检查所有朝向及转角是否仍完整。
- 检查物件的上下层关系。被遮住的底部不等于不存在；新增地板或装饰不能擦掉其必要部分。
- 区分物件的图像边界、视觉占地和玩家可站位置。透明像素不自动意味着此处适合通行。
- 朝向不同的家具须有已核实的素材支持。缺少侧向图块时，调整布局或使用已授权的替代组合。
- 同类物件允许共享组合模板，但每次仍核对使用面、周围通道和当地照明关系。

### 从 Sample 形成项目约定

| 观察对象 | 需要记下的关系 | 如何用于新地图 |
| --- | --- | --- |
| 墙体与天花 | 墙高、转角、门洞、遮挡方式 | 沿用同一建筑语言，按新功能安排房间 |
| 大型家具 | 完整拼接、朝向、落地位置、使用侧 | 放入功能区时一起预留占地与接近空间 |
| 地面材料 | 主材、边缘、区域分界、磨损方式 | 用材料表达使用区域与交通，不任意换色 |
| 树群或岩体 | 前后遮挡、边缘、底部、组合变化 | 复用合法组合，重新组织地形与活动空间 |
| 视觉气氛 | 明暗、色彩、细节密度、阴影习惯 | 保持项目一致性，并核对可读性 |

把“这套柜台怎样拼”与“Sample 把柜台放在哪里”分开记录。新图可以共享全部素材组合而采用不同功能分区。
样本没有覆盖的组合应先在临时地图中试拼并查看。未经观察的用途保留为待核实项，不能进入批量生成模板。

## 2. 用功能关系组织空间

先确定场所中的人或物为什么聚集、移动、停留，再决定房间轮廓。使用设计卡记录已有任务要求；填写卡片不授权新增机制。

1. 列出已要求的活动与交互，例如经过、接待、等候、工作、休息或观看。
2. 把活动归入功能区，并注明必须相邻、需要分隔、适合看见以及需要安静的关系。
3. 放置既有入口、出口和必要交互点，明确公共区域、内部区域与已有条件限制。
4. 用通道连接功能区，检查使用者有没有被迫穿过不相关的工作区或私密空间。
5. 根据实际路线与完整物件占地确定外轮廓，再核对楼体或地形背景。

例如，同一套“柜台＋座椅＋储物柜”可组成不同场所：接待区让柜台面对入口、座椅位于可看见服务位置的等候区；维护区让工作台靠近设备与工具储存、座椅位于休息角。差异来自相邻关系与使用方向。

有多个方案时，比较它们如何满足功能、视线和既有事件。不要把 U、L、S 或 O 字形当作场所类型，也不要为了凑不同字形强行制造绕行。
路径中的绕行、死端或折返应有可说明的作用：避开设备、抵达独立房间、形成视线变化，或承载项目已有的探索内容。无作用的路程可以缩短。

## 3. 确定尺度与玩家视口

尺度依据来自项目实际画面和活动空间。先核实角色大小、地图格子、分辨率、相机、移动方式及相关插件，不把默认参数套到所有项目。

- 用完整家具和人的使用关系估计尺寸：桌边需要站位，柜门或设备操作面需要接近空间，演出需要演员到达位置。
- 对照已有地图确定项目的抽象程度。建筑外观与室内不必按真实比例等大，但入口方向和空间关系应容易理解。
- 从能容纳必要内容的范围开始；确需表达辽阔、隔离、危险或拥挤时，再有目的地改变尺度。
- 空地可以承担会合、表演、运动、对比或压迫感。把空地缩掉前，先检查它是否服务场景。
- 大地图应有可识别的区域差别与认路信息；小地图要避免频繁转场切断本来连续的活动。
- 通道宽度按实际需求检查：独行、NPC 对向移动、队伍演出、既有敌人回避等需求可能不同。

### 用实际视口复核

在入口、主要转向、既有交互点和出口附近，查看玩家能看到的内容；必要时补看转向前后。位置重合可以合并检查。
每个画面要能解释当前场所与下一步的可能方向。需要遮蔽或迷惑玩家时，说明这是项目已有的体验目标。
检查重要对象是否被前景、同色背景或密集装饰淹没；检查物件是否看起来能接近而实际上没有站位。
整图美观不能代替视口检查。相同墙面、同样转角或相同空厅连续占据多个画面时，应评估行走过程是否缺少变化。
为演员、交互反馈和玩家注意力保留空间；入口处不必同时展示所有地标，也不必把每屏都装满。

## 4. 室内与人工空间

### 建筑关系

- 房间轮廓应能说明建造或改造原因。凹角适合柱网、设备间、楼梯间或结构差异；无依据的凹角只会增加拼接负担。
- 沿同一楼层核对墙高、地台与楼梯终点。存在高差时，把地面标高与墙面可见高度一起考虑。
- 核对门、窗、楼梯与外部空间的关系。楼梯不能在表达上通入实墙，窗户不应无故开向同层内部实体。
- 柱、护栏、柜台和隔断可以组织空间，但应保留必要通行、视线和已有演出位置。
- 采用矩形、对称、中轴或长直走廊可以符合真实功能。重点是这些结构如何安排入口、房间和活动。

### 家具关系

- 先摆决定用途的大物件，再安排交通与小物件。尺寸放不下时，重新评估房间，而不是切掉床脚或机台端头。
- 家具按使用关系成组：工具靠工作位，等候座椅靠服务区，观众席朝观看对象，储物靠需要取用的人。
- 给每组物件确定主次。大量同等醒目的装饰会削弱设备、门和既有交互对象的辨识度。
- 多朝向组合可以丰富布局，但必须符合可用素材。全体家具靠北墙的现象应先检查素材能力与功能选择。
- 生活痕迹应局部聚集于使用区域；书、杯子、线缆、箱子等不需要平均分配到整个房间。
- 同一建筑可共享墙面、地板、标识和照明节奏；职能不同的区域可以通过家具朝向、分隔和活动中心区分。

## 5. 自然地形

先确定地形、水体、植被与人为使用的关系，再分配细节。自然感需要有条件的变化；每格随机抖动会产生另一种机械纹理。

- 先安排山体、林地、水面与空地等主要块面，预留玩家活动空间，再处理边缘与局部细节。
- 检查连通平台的高差关系；相同轮廓下突然变高或变低，需要相应坡面、台阶或断面表达。
- 让崖线和岸线在较大尺度上有方向与段落，小尺度变化服从地形，不必逐格凹凸。
- 道路表达使用程度：常用通路连接实际目的地，少用路径可逐渐破碎、被植被覆盖或进入项目已有的隐蔽区域。
- 森林的密林、林缘、空地与独立树各有作用。核对树木完整性与遮挡，避免局部组合留下不合理接缝。
- 植被、碎石和地面变化按位置组织：湿润处、崖脚、树下、路边和人工整理区域可以不同。
- 水源、岩体或建筑遗存可形成辨识点；其具体功能以项目既有设定为准，不能顺便添加宝箱或支线。
- 不可进入的背景仍应与可进入区域在材质、季节和地形上连续，但细节投入可随可见程度调整。
- 沙漠、雪原、荒地可以稀疏。需要认路时，利用地形轮廓、方向线索或现有地标，不靠重复撒装饰填满。

人工林可以成排，河渠可以笔直，采石面可以方正，洞穴也可以包含规则结构。环境形成原因决定是否合适。

## 6. 批次差异与合理重复

先查看整批地图的功能卡和粗布局，再精修单图。保持同一素材语言时，优先改变功能相邻关系、活动中心与画面节奏。

| 比较层面 | 需要观察的差异 | 常见无效变化 |
| --- | --- | --- |
| 功能组织 | 服务、工作、停留和交通区域如何相接 | 只给同一房间换地点名称 |
| 路线体验 | 目的地位置、选择、必要回返与信息出现顺序 | 同一绕行路线旋转或镜像 |
| 视觉组织 | 主对象、开合、前后景与空地的分布 | 换地板后仍保留全部家具位置 |
| 地方特征 | 材料组合、使用痕迹和设备的区域关系 | 每图随机增加一件装饰 |

重复本身有表达作用：酒店客房、宿舍单元、影院座椅和站台构件可以标准化。检查标准单元如何组成不同区域，而非强迫每个单元独一无二。
结构相近的线性地图也可能成立；评估玩家接触的场所、视野、既有事件和行动节奏，不凭图结构同构判失败。
如果多张用途不同的地图都围绕同一个中心障碍走一圈，要求逐张说明原因。缺少功能依据的重复应在粗布局时修正。
对照图保留真实宽高比，并统一格子比例或标明缩放。不要用不同裁切掩盖重复，也不要用统一方框制造看似相同的轮廓。
不设置固定装饰占比、统一路线字形、必需环路数量或审美分数；这些指标不能代替具体画面与使用关系。

## 7. 现代区域的九类地点示例

以下是原创的布局思考示例，展示同一套现代素材如何服务不同功能。它们不是对当前工程的事实描述，也不授权新增门禁、交互、收费、小游戏、奖励或其他玩法；只使用任务已要求的区与物件。

| 地点 | 可据用途组织的相邻关系 | 应重点核对的空间特点 |
| --- | --- | --- |
| 换乘站 | 入口与导向连接候车区域，候车区域接近相应通道或站台 | 主要目的地方向清楚；等候和穿行空间相互协调 |
| 维护区 | 设备、操作面、工具与零件储存相邻，工作区接入交通空间 | 设备维护空间完整；线路与工具组合具有用途 |
| 街机厅 | 机台按完整组排列，操作面朝向可站区域，组间连接既有服务点 | 玩家站位与穿行不互相占用；主机台组可辨认 |
| 夜店 | 已有舞池、吧台、座位及舞台按观看与停留关系组织 | 大小空间有节奏；灯光不淹没入口和交互对象 |
| 酒店 | 接待面向抵达空间，交通区连接客房，等候区靠近服务区 | 公共区域与重复客房形成层次；入口至目的地易理解 |
| 宿舍 | 床位与个人储物成单元，已要求的共享设施接入公共空间 | 重复单元表现共同生活；每个使用面仍可接近 |
| 健身房 | 器械按使用方式成组，既有自由活动区与交通空间相接 | 器械完整占地和活动空间可信；不靠器械堵塞空白 |
| 泳馆 | 池体、池边与已要求的进入路线相连，配套区按使用顺序接入 | 池边与水面的边界清楚；围池路线有合理作用 |
| 影院 | 抵达空间连接影厅入口，座椅朝向银幕并接入过道 | 观看方向明确；排布、通道和银幕形成完整空间 |

如果素材只支持某些对象，就选择能被正确表达的功能关系。不要仅把九张图换成九种字母轮廓，也不要为达成表中示例擅自补齐未要求的设施。

## 8. 按证据修正设计

发现问题时，写清地图、区域或坐标、画面表现及影响，并回到相应阶段修改：功能不清先改分区，空走过长先改路线，物件残缺先改拼接。
新增装饰、调色、灯光或视差效果不能证明上述问题已解决；修改后重新查看受影响的全图与实际视口。
完整验收记录使用 [design-contracts.md](design-contracts.md)，工程与运行条件使用 [engine-workflow.md](engine-workflow.md)。明确哪些判断来自实图、运行结果或尚待核实的推测。
